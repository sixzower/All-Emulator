# PlayLab

เว็บรวมอีมูเลเตอร์สำหรับทดสอบเกมแปลไทย รันในเครื่องคนเดียว ไฟล์เกมไม่ถูกอัปโหลดไปไหน

## วิธีใช้
```
python serve.py
```
เปิด http://localhost:8000
- **เครื่องเบา–กลาง** (GBA, SNES, PS1, DS ฯลฯ): แตะไอคอน → เลือกไฟล์เกม → เล่นในหน้าเว็บ พร้อมแคปจอ โน้ตบั๊ก เซฟด่วน
- **เครื่องหนัก** (3DS, PS2, GameCube/Wii, Switch, Dreamcast): แตะไอคอน → เลือกเกมจากรายการ → เปิดด้วยโปรแกรมอีมูในเครื่อง (หน้าต่างแยก)

ครั้งแรกต้องต่ออินเทอร์เน็ตเพื่อโหลดตัวอีมูจาก CDN ของ EmulatorJS (ฝั่งเว็บ)

## เปิดเป็นเว็บบน GitHub Pages
โปรเจกต์เป็นไฟล์ static (ไม่มีไฟล์เกมหรือ BIOS อยู่ใน repo) ใช้ GitHub Pages ได้: Settings → Pages → Source: *Deploy from a branch* → เลือก branch หลัก และโฟลเดอร์ `/ (root)` → Save จากนั้นเข้าที่ `https://<ชื่อผู้ใช้>.github.io/All-Emulator/`
เวอร์ชันออนไลน์เล่นเกมในเว็บได้ตามปกติ (ไฟล์เกมอ่านในเครื่องผู้ใช้ ไม่ถูกอัปโหลด) แต่ฟีเจอร์ที่ต้องใช้ `serve.py` (เปิด 3DS/PS2/Wii ด้วยโปรแกรมในเครื่อง และช่องใส่ BIOS) จะถูกซ่อน และ PSP ในเว็บมักเปิดไม่ติดเพราะ Pages ตั้ง header ที่ต้องใช้ไม่ได้

## เปิดเป็นเว็บบน Vercel (รองรับ PSP ในเว็บ)
มีไฟล์ `vercel.json` ตั้ง header ที่ PSP ต้องใช้ไว้ให้แล้ว (`Cross-Origin-Opener-Policy: same-origin` และ `Cross-Origin-Embedder-Policy: credentialless`) ไม่ต้องมีขั้นตอน build:
1. เข้า https://vercel.com → Add New → Project → นำเข้า repo `All-Emulator`
2. Framework Preset: **Other** · Build Command และ Output Directory: ปล่อยว่าง
3. ถ้า branch หลักของ repo ไม่ใช่ branch ที่ต้องการ ไปที่ Settings → Git → Production Branch แล้วเลือกให้ถูก
4. Deploy

ตรวจว่าเปิดโหมดหลายเธรดสำเร็จ: เปิดเว็บ กด F12 แล้วพิมพ์ `crossOriginIsolated` ใน Console ต้องได้ `true` (ทำงานบน Chrome/Edge เท่านั้น Safari ยังไม่รองรับ header นี้) ใช้ `python serve.py --isolate` ทดสอบในเครื่องได้เหมือนกัน
PSP ยังหนักมาก ถ้ากระตุกแนะนำ PPSSPP

## ลากไฟล์เกมมาวางตรงไหนก็ได้
ลากไฟล์เกมมาวางที่ไหนของหน้าคลังก็ได้ (หรือกดการ์ด "ลากไฟล์เกมมาวางตรงไหนก็ได้" เพื่อเลือกไฟล์) ระบบเลือกเครื่องให้เองโดย:
1. ดูนามสกุลไฟล์ เช่น `.gba` `.sfc` `.nds` `.z64` ที่ใช้เครื่องเดียว เปิดทันที
2. ถ้านามสกุลใช้ได้หลายเครื่อง (`.iso` `.bin` `.cue` `.chd`) อ่านหัวไฟล์ดูข้อความประจำแผ่น/ตลับ เช่น PS1, PSP, Saturn, Mega CD, Mega Drive, GameCube/Wii, 3DS
3. ถ้าเป็นไฟล์ `.zip` อ่านรายชื่อไฟล์ข้างในเพื่อดูว่าเป็นเกมเครื่องอะไร
4. ถ้ายังเดาไม่ได้จริงๆ จะถามให้เลือกเครื่องจากรายการที่เป็นไปได้ (มีปุ่มดูเครื่องทั้งหมด)

เกมที่เปิดด้วยโปรแกรมในเครื่อง (3DS ฯลฯ) จะบอกให้ไปที่หน้าของเครื่องนั้น วางตรงไหนก็ตาม (รวมถึงบนไอคอนเครื่อง) ระบบเดาเครื่องจากตัวไฟล์เสมอ ไม่ผูกกับไอคอนที่ลากไปโดน วางได้ทีละไฟล์ เกมแผ่นแบบ `.cue` + `.bin` ให้บีบเป็น `.zip` หรือแปลงเป็น `.chd` ก่อน

## ปุ่มลัดที่ตั้งให้
- **Fast Forward = Space** เป็นค่าตั้งต้นของทุกเครื่อง (เปลี่ยนได้ในเมนู Control Settings ของอีมูตามเกม) เกมที่เคยเปิดไว้และยังไม่มีปุ่ม Fast Forward จะถูกใส่ Space ให้ตอนเปิดครั้งถัดไป เกมที่ตั้งปุ่มนี้ไว้เองแล้วจะไม่ถูกแก้ทับ
- **Shift = แคปจอ** (ไม่ทำงานตอนพิมพ์โน้ตหรือเปิดหน้าต่างอยู่)

## ฟีเจอร์ช่วยทดสอบคำแปล (หน้าเล่น)
- **โน้ตบั๊ก**: เลือกประเภท (ฟอนต์ / ข้อความล้น / คำผิด / สระ-วรรณยุกต์ / ผ่าน) พิมพ์รายละเอียด และแนบภาพแคปไปกับโน้ตได้
- **ภาพแคป**: แตะดูเต็มจอ วาดวงกลม/ขีดเส้นชี้จุดที่ผิด (ปุ่มดินสอ) จดโน้ตพร้อมแนบภาพ (ปุ่มโน้ต) ลบ และบันทึกทั้งหมดเป็น .zip ภาพเก็บไว้ในเบราว์เซอร์ ปิดแล้วเปิดใหม่ยังอยู่
- **ปุ่ม "ควบคุม"**: ดูปุ่มของเครื่องนั้นและคีย์บอร์ดที่ตรงกัน

## หน้าตา
- ไอคอนเครื่องแต่ละเครื่องมีรูปทรงของตัวเอง กดแล้วไอคอนขยายเต็มจอเข้าหน้าเล่น และหดกลับเข้าไอคอนเดิมตอนกด "กลับคลัง"
- โหมดสว่าง/มืด: ปุ่มวงกลมที่มุมขวาบน (แตะสลับ กดค้างกลับไปตามระบบ)

## BIOS (PS1 / Mega CD / Saturn)
เมื่อเปิดเกมของเครื่องที่ใช้ BIOS เว็บจะถามให้เลือกไฟล์ BIOS ที่คุณมี (PS1 ไม่บังคับ) ครั้งหน้าไม่ต้องเลือกซ้ำ จัดการ/เปลี่ยน/ลบได้จากแถว "จัดการ BIOS" ท้ายหน้าแรก
- **เว็บออนไลน์ (Vercel / GitHub Pages):** ไฟล์เก็บในเบราว์เซอร์ของคุณ (IndexedDB) ไม่ถูกอัปโหลดไปที่ไหน ถ้าล้างข้อมูลเบราว์เซอร์ต้องเลือกใหม่
- **รันด้วย `python serve.py`:** ไฟล์เก็บในโฟลเดอร์ `bios/` ในเครื่อง (ไม่ถูก commit)

## ตั้งค่า "เปิดด้วยโปรแกรมในเครื่อง" (3DS ฯลฯ)
1. ติดตั้งอีมูของเครื่องนั้น เช่น 3DS ใช้ [Azahar](https://azahar-emu.org), PS2 ใช้ [PCSX2](https://pcsx2.net), Wii ใช้ [Dolphin](https://dolphin-emu.org), PSP ใช้ [PPSSPP](https://www.ppsspp.org)
2. เปิดไฟล์ `emulators.json` แก้ 2 ค่าของเครื่องที่ใช้:
   - `exe` = ที่อยู่โปรแกรมอีมู (ใน Windows ใช้ `\\` แทน `\` เช่น `C:\\Emulators\\Azahar\\azahar.exe`)
   - `games` = โฟลเดอร์ที่เก็บไฟล์เกม (ค้นหาในโฟลเดอร์ย่อยได้ลึก 4 ชั้น)
3. แก้ไฟล์แล้วกดไอคอนเครื่องในเว็บอีกครั้ง ไม่ต้องรีสตาร์ท `serve.py`

เครื่องที่ไม่ได้ใช้ ปล่อยค่าเดิมไว้ได้ หน้าเว็บจะบอกว่าต้องตั้งค่าอะไรเมื่อกดไอคอน

ความปลอดภัย: เซิร์ฟเวอร์เปิดรับเฉพาะเครื่องนี้ (127.0.0.1) สั่งเปิดได้เฉพาะโปรแกรมที่อยู่ใน `emulators.json` กับไฟล์ในโฟลเดอร์เกมที่นามสกุลตรงเท่านั้น และไม่รับคำสั่งจากเว็บไซต์อื่น

## ใช้ออฟไลน์ (ไม่บังคับ)
ดาวน์โหลดโฟลเดอร์ `data` ของ EmulatorJS (https://github.com/EmulatorJS/EmulatorJS) มาวางที่ `emulatorjs/data/` เว็บจะใช้ตัวนี้ก่อนอัตโนมัติ


## เพิ่มเครื่องใหม่
- เครื่องที่เล่นในเว็บ: แก้ `js/systems.js` เพิ่มหนึ่งบรรทัด (ชื่อ core, นามสกุลไฟล์, สีไอคอน)
- เครื่องที่เปิดด้วยโปรแกรมในเครื่อง: เพิ่มใน `NATIVE` ของ `js/systems.js` และส่วนที่ตรงกันใน `emulators.json`

## หมายเหตุ
- ปุ่ม "กลับ" ในหน้าเล่น รีโหลดหน้าเพื่อคืนหน่วยความจำให้เครื่อง RAM น้อย
- PSP: ถ้าตั้ง PPSSPP ไว้ใน `emulators.json` เมื่อกดไอคอน PSP จะมีตัวเลือก "เปิดด้วย PPSSPP" ซึ่งเบากว่าเล่นในเว็บ
