# All-Emulator

เว็บรวมอีมูเลเตอร์สำหรับทดสอบเกมแปลไทย รันในเครื่องคนเดียว ไฟล์เกมไม่ถูกอัปโหลดไปไหน

## วิธีใช้
```bash
python serve.py
```
เปิด http://localhost:8000 → แตะไอคอนเครื่อง → เลือกไฟล์เกม (หรือลากไฟล์มาวางบนไอคอน) → เล่นและจดโน้ตบั๊กได้ทันที
ครั้งแรกต้องต่ออินเทอร์เน็ตเพื่อโหลดตัวอีมูจาก CDN ของ EmulatorJS

## ใช้ออฟไลน์ (ไม่บังคับ)
ดาวน์โหลดโฟลเดอร์ `data` ของ EmulatorJS (https://github.com/EmulatorJS/EmulatorJS) มาวางที่ `emulatorjs/data/` เว็บจะใช้ตัวนี้ก่อนอัตโนมัติ
core ของ PSP ต้องใช้ `python serve.py --isolate` ร่วมกับโหมดออฟไลน์นี้

## เพิ่มเครื่องใหม่
แก้ `js/systems.js` เพิ่มหนึ่งบรรทัด (ชื่อ core, นามสกุลไฟล์, สีไอคอน)

## หมายเหตุ
- PS1/Saturn/Mega CD บางเกมอาจต้องใช้ BIOS ซึ่งยังไม่มีช่องใส่ในเวอร์ชันนี้
- ปุ่ม "กลับ" รีโหลดหน้าเพื่อคืนหน่วยความจำให้เครื่อง RAM น้อย
- PS2, Wii, 3DS, Switch, Dreamcast รันในเว็บไม่ได้ (แสดงเป็นไอคอนสีเทา)
