# All-Emulator

เว็บรวมอีมูเลเตอร์สำหรับทดสอบเกมแปลไทย รันในเครื่องคนเดียว ไฟล์เกมไม่ถูกอัปโหลดไปไหน

## วิธีใช้
```
python serve.py
```
เปิด http://localhost:8000
- **เครื่องเบา–กลาง** (GBA, SNES, PS1, DS ฯลฯ): แตะไอคอน → เลือกไฟล์เกม → เล่นในหน้าเว็บ พร้อมแคปจอ โน้ตบั๊ก เซฟด่วน
- **เครื่องหนัก** (3DS, PS2, GameCube/Wii, Switch, Dreamcast): แตะไอคอน → เลือกเกมจากรายการ → เปิดด้วยโปรแกรมอีมูในเครื่อง (หน้าต่างแยก)

ครั้งแรกต้องต่ออินเทอร์เน็ตเพื่อโหลดตัวอีมูจาก CDN ของ EmulatorJS (ฝั่งเว็บ)

## ตั้งค่า "เปิดด้วยโปรแกรมในเครื่อง" (3DS ฯลฯ)
1. ติดตั้งอีมูของเครื่องนั้น เช่น 3DS ใช้ [Azahar](https://azahar-emu.org), PS2 ใช้ [PCSX2](https://pcsx2.net), Wii ใช้ [Dolphin](https://dolphin-emu.org), PSP ใช้ [PPSSPP](https://www.ppsspp.org)
2. เปิดไฟล์ `emulators.json` แก้ 2 ค่าของเครื่องที่ใช้:
   - `exe` = ที่อยู่โปรแกรมอีมู (ใน Windows ใช้ `\\` แทน `\` เช่น `C:\\Emulators\\Azahar\\azahar.exe`)
   - `games` = โฟลเดอร์ที่เก็บไฟล์เกม (ค้นหาในโฟลเดอร์ย่อยได้ลึก 4 ชั้น)
3. แก้ไฟล์แล้วกดไอคอนเครื่องในเว็บอีกครั้ง ไม่ต้องรีสตาร์ท `serve.py`

เครื่องที่ไม่ได้ใช้ ปล่อยค่าเดิมไว้ได้ หน้าเว็บจะบอกว่าต้องตั้งค่าอะไรเมื่อกดไอคอน

ความปลอดภัย: เซิร์ฟเวอร์เปิดรับเฉพาะเครื่องนี้ (127.0.0.1) สั่งเปิดได้เฉพาะโปรแกรมที่อยู่ใน `emulators.json` กับไฟล์ในโฟลเดอร์เกมที่นามสกุลตรงเท่านั้น และไม่รับคำสั่งจากเว็บไซต์อื่น

## ใช้ออฟไลน์ (ไม่บังคับ)
ดาวน์โหลดโฟลเดอร์ `data` ของ EmulatorJS (https://github.com/EmulatorJS/EmulatorJS) มาวางที่ `emulatorjs/data/` เว็บจะใช้ตัวนี้ก่อนอัตโนมัติ
core ของ PSP ต้องใช้ `python serve.py --isolate` ร่วมกับโหมดออฟไลน์นี้

## เพิ่มเครื่องใหม่
- เครื่องที่เล่นในเว็บ: แก้ `js/systems.js` เพิ่มหนึ่งบรรทัด (ชื่อ core, นามสกุลไฟล์, สีไอคอน)
- เครื่องที่เปิดด้วยโปรแกรมในเครื่อง: เพิ่มใน `NATIVE` ของ `js/systems.js` และส่วนที่ตรงกันใน `emulators.json`

## หมายเหตุ
- PS1/Saturn/Mega CD บางเกมอาจต้องใช้ BIOS ซึ่งยังไม่มีช่องใส่ในเวอร์ชันนี้
- ปุ่ม "กลับ" ในหน้าเล่น รีโหลดหน้าเพื่อคืนหน่วยความจำให้เครื่อง RAM น้อย
- PSP: ถ้าตั้ง PPSSPP ไว้ใน `emulators.json` เมื่อกดไอคอน PSP จะมีตัวเลือก "เปิดด้วย PPSSPP" ซึ่งเบากว่าเล่นในเว็บ
